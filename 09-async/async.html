Asynchronous JavaScript (async)

Asynchronous programming allows JavaScript to perform long-running tasks (network requests, timers, file I/O) without blocking the main thread. This makes applications more responsive by handling work in the background and continuing execution when the result is ready.

Callbacks

Callbacks are functions passed as arguments that run after an asynchronous operation completes. They work but can lead to nested "callback hell" when chaining multiple async steps.

// Example callback
setTimeout(() => {
  console.log('Done after 1 second');
}, 1000);

Promises

Promises represent a future value and make chaining asynchronous operations easier and more readable.

// Example Promise
fetch('/data.json')
  .then(response => response.json())
  .then(data => console.log(data))
  .catch(err => console.error(err));

Async / Await

Async/await is built on promises and provides a synchronous-looking syntax for asynchronous code, improving readability.

// Example async/await
async function loadData() {
  try {
    const response = await fetch('/data.json');
    const data = await response.json();
    console.log(data);
  } catch (err) {
    console.error(err);
  }
}

loadData();
